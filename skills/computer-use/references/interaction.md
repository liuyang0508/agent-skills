# 定位、坐标与恢复

## 操作对象

DOM/AX名称只是定位线索：检查唯一性、所属区域、可见性和可操作状态。原工具返回的元素编号可能在下一次观察后改变。菜单和弹窗可属于系统窗口而非网页；网页截图不含它们时改用允许的应用观察或键盘路径。

## 坐标契约

先分清四个东西：原始捕获区域、交给模型的图像区域、缩放/裁剪/留白、驱动接受的坐标单位与原点。DPR不能统一写死为2，OS全屏像素也不能自动当作浏览器CSS坐标。窗口、标签页、滚动或缩放发生变化后旧转换失效。

仅在真实元数据已知时使用 `scripts/map_coordinates.py`：

```sh
python3 scripts/map_coordinates.py --frame examples/frames/cropped.json --x 672 --y 384
```

`image_rect` 是交付图像中真实内容的位置，排除留白；`tool_rect` 是这块内容在驱动坐标中的位置。脚本按两个轴做缩放和平移；拒绝内容区外坐标、非法尺寸及非有限数值。它不验证图像新鲜度，也不执行点击；不支持旋转、透视或未知的隐式图像变换。

模型输入、预览页面和点击驱动必须共享同一帧的转换。定位困难时先修正捕获/尺寸/坐标空间，再考虑支持的局部缩放、键盘导航或更清楚的截图，不默认加网格或把图像切成多个无坐标关系的块。

## 失败处理

| 证据 | 下一步 |
| --- | --- |
| 元素不存在或不可见 | 新观察；检查页面、窗口、弹窗和滚动位置 |
| 点击落在邻近控件 | 核对真实图像尺寸、裁剪/留白与驱动坐标单位 |
| 动作超时，保存/提交结果未知 | 回读对象或结果列表；确认未发生才重试 |
| 出现新权限或登录步骤 | 按宿主要求确认/接管，不能扩大原任务范围 |
| 依赖动作中的前一步失败 | 停止后续动作，报告实际未执行项，再基于新状态规划 |
| 多次观察无进展 | 诊断或改用确实可行的路线，保留已完成结果和缺口 |

示范流程只提供任务结构，不能当作固定坐标回放。结合当前UI找到等价控件；对象、金额和收件人仍由本次请求决定。
