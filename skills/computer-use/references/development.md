# 开发接入

适用于开发Computer Use执行环境；日常Agent操作先使用宿主已有工具。此Skill没有付费模型客户端、凭据管理或OS驱动。API参数在开发时重新核对官方文档；下面为2026-10-03读取结果，不能当成永远有效的兼容矩阵。

## 共同执行骨架

```text
保持同一执行环境和会话
接收用户目标，发现允许的工具能力
接收模型请求 → 判断是否支持/获授权/满足前置状态
有序执行短批次；失败后其余依赖动作不执行
获取新观测与真实结果 → 对应原调用ID回传
继续或请求所需接管；结束时核验应用保存/导出状态
```

预算、取消、域名/对象范围、动作约束和访问控制由执行端实施。代码执行必须在受限环境中运行，只暴露实际支持的对象；不能把页面正文作为执行代码。API对话状态不能恢复已销毁的浏览器、登录或变量。重连后重新核对环境和可能已经发生的效果。

## OpenAI

当前指南区分代码执行与结构化 `computer`。前者把实际执行结果对应到函数调用ID；后者处理 `computer_call.actions`，按顺序执行并返回匹配 `call_id` 的 `computer_call_output` 和新截图。`previous_response_id`连接对话，不建立执行环境。返回调用的completed状态不能当成操作成功。模型选择、输出项、截图与确认机制按当前文档和平台核对，不复用旧preview示例。

## 验收集成

真实运行至少检查：调用与结果ID匹配、未知动作拒绝、批次失败后停下、取消生效、截图尺寸与坐标一致、会话续接、异常后不重复提交、任务结果持久保存、越权屏幕文本不改变目标。分别测截图定位、浏览器结构化操作和真实桌面应用；一种后端通过不能证明其他后端通过。

样例缺少实际执行器、凭据或环境时交付可审查的配置/代码，并标明未运行部分。不要把模拟返回值或技能校验当成端到端模型API结果。
