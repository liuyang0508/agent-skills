# 验证

运行 `python3 -m unittest discover -s evals -v`。行为用例验证实际保存与恢复、双视图、引用保留、生成例子标识、四类完整续接、版本差异、反馈后的解释与拒绝测验；包含无来源、指定格式不可用、未知引用、假同意、无历史等边界。

发布时要求至少 48 个通过的固定行为用例，并对真实请求做独立前向验证。逐项给出 R1–R6 观察结果；缺失实现不能靠“本例不适用”通过。

工具检查只证明确定性契约和产物不丢原始数据。Agent 还需核对教学辅助、重写解释与图表语义，并打开真实产物检查可读性和交互。Receipt 明确区分人工未检查与工具通过。

用户效果试验以同一事实结果和同一理解任务对比原文字：记录答题准确率、定位依据时间、完成操作时间、生成等待和成本。随机化顺序、记录样本量；不要把模型 Judge 或静态测试当作真实人类理解指标。首版不声称已有理解时间提升数据。
