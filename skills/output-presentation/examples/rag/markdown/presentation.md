# RAG 如何把资料带进回答

RAG 先检索相关资料，再结合资料生成回答。检索结果仍需要核验。

## 理解要点

- 说明检索和生成如何连接
- 知道为何还需核验

RAG 把检索和生成结合起来。检索器取得相关资料。生成模型使用资料与问题生成回答。

- 用户问题 → 检索器：发起检索
- 检索器 → 相关资料：取得片段
- 相关资料 → 生成模型：提供上下文
- 生成模型 → 待核验回答：生成回答
- 用户问题 → 生成模型：提供问题

1. 先形成检索请求。
2. 从资料源取得相关片段。
3. 把片段与问题交给生成模型。
4. 对照依据核验回答。
