RAG 如何把资料带进回答

RAG 先检索相关资料，再结合资料生成回答。检索结果仍需要核验。

点击图中的节点，可以查看与它有关的输入、输出关系及来源。

理解要点

  • 说明检索和生成如何连接
  • 知道为何还需核验

RAG 把检索和生成结合起来。检索器取得相关资料。生成模型使用资料与问题生成回答。

重点

点击图中的节点，查看相关关系与依据。

沿图中的顺序查看过程。

  1. 先形成检索请求。
  2. 从资料源取得相关片段。
  3. 把片段与问题交给生成模型。
  4. 对照依据核验回答。
假设示例

假设检索器取到了过期说明。模型即使使用这段资料，也可能给出不适用于当前情况的回答。

假设：仅用于说明检索资料的适用性问题；不代表任何实际产品或实测结果
