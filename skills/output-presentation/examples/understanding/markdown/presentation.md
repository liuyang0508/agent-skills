# 复杂结果，怎样才容易理解？

先明确需要理解什么。再选合适的表达形式。始终保留依据、限制和继续思考的入口。

## 理解要点

- 知道如何按理解任务选择表达形式
- 分清表达清楚与内容正确

模型给出结果。你还需要理解结论、核验依据，并决定下一步。先明确需要理解什么。再选合适的表达形式。保留原始事实、依据和限制。

- 原始结果 → 理解目标：明确目标
- 理解目标 → 合适的表达：选择形式
- 合适的表达 → 核验与续接：保留依据

| 表达形式 | 适合的理解任务 | 本例产物 |
| --- | --- | --- |
| 清晰文字 | 读懂结论与步骤 | 短句说明与完整原文 |
| SVG 图解 | 看清方向与关系 | 可缩放的流程图 |
| 交互网页 | 主动探索与核验 | 节点、搜索与依据切换 |
| 讲解视频 | 跟随时间理解过程 | 二维动画、旁白与字幕 |

六项能力贯穿不同形式。先明确理解目标。把解释与核验连起来。用反例照亮边界。为下一步准备完整任务。结果更新时先看变化。围绕当前困惑重新解释。

## 假设示例

假设一份分析引用了过期资料。即使把分析做成精美网页和视频，结论仍可能不适用于当前情况。

假设：仅用于区分清晰表达与事实正确；不代表实测效果或实际业务结论

## 术语

- **理解目标**：看完后需要分清的关系、找到的依据或完成的判断。
- **核验**：对照原始内容、来源和限制检查结论。
- **续接**：把当前问题与依据组织成可继续交给 Agent 的任务。

## 依据与限制

- Karpathy：帮助理解模型输出的四类表达方向：https://x.com/karpathy/status/2105819303471976479
- Output Presentation 0.2.0：输出形式与六项能力：https://github.com/liuyang0508/agent-skills/blob/37f1046e3cbecf0c004e954039f5b8653bf7d07d/skills/output-presentation/SKILL.md

- 四种形式按理解任务选择。本例为了比较才同时生成四种产物。六项能力为本 Skill 的扩展，不是 Karpathy 原帖列出的功能。
- 表达更清楚不能证明内容正确，也不能证明读者已理解。仍需核验原始依据与适用条件。
- 静态网页可以查看已有内容并准备后续任务。改变假设后，需要把任务交给 Agent 才会继续研究或重算。
- 写作模式不声明 ASD-STE100 合规。视频链路生成二维场景、本地旁白和字幕；复杂三维场景需相应工具。

## 继续思考

- 核验所列结论、原始依据、单位与限制；无法读取来源时明确缺口。
- 按一致维度比较所列内容；缺失数据标记未知，不能补造。
- 在独立假设场景中分析这些内容；新研究或重算交回上游，保留真实结果。
- 检查结论的依据、适用边界和薄弱环节；区分已验证问题与待调查假说。
